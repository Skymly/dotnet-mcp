# dotnet-mcp

一个面向 .NET 的 MCP（Model Context Protocol）服务器，目标能力：

- **多语言**：C#、VB.NET、F#
- **互操作与 DLR**：COM Interop、`dynamic` 等场景的符号分析
- **XAML**：语义级 XAML 分析，与 code-behind 符号联动
- **源生成器特别支持**：区分每个成员由哪个 Source Generator 生成
